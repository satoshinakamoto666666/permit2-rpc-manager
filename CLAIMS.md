# Epistemic Claims Ledger (`CLAIMS.md`)

Every mathematical claim, invariant computation, external theorem, and open problem in this repository is explicitly classified into one of four epistemic categories:
- **`PROVED`**: Proved unconditionally from first principles and exact integer/interval arithmetic inside this repository.
- **`COMPUTED`**: Computed by deterministic, pure-integer algorithms in `src/` and cross-checked against `data/allbsd_upto_100.txt`.
- **`CITED`**: Invoked from peer-reviewed published mathematics with explicit citation and hypothesis check.
- **`OPEN`**: Unsolved in full generality as part of the Clay Millennium Problem for arbitrary elliptic curves over $\mathbb{Q}$.
